# Book Blindbox（拆书盲盒 · 暗金礼盒风）

一个纯前端网页小玩具：把想读的书丢进不透明礼盒里，拆到哪本就读哪本。

## 运行

- 直接双击打开 `index.html` 也能用（本地数据会存浏览器）。
- 更推荐用本地静态服务器（避免部分浏览器限制）：

```bash
cd book-blindbox-web
python3 -m http.server 5173
```

然后访问 `http://localhost:5173/`。

## 数据

- 书库与记录都保存在浏览器 `localStorage`（换设备或清缓存会丢）。

## 使用方式

- 首页是“盲盒池”：每个礼物盒固定对应一本书（你不知道是哪本）。
- 点击任意礼物盒会弹出开箱舞台并揭晓；点“我就读它”会把这本移到“正在读”，对应礼物盒会从池子里消失。
